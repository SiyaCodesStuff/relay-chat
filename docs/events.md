# Socket event contract

Connect to the Socket.IO server with the `relay_session` cookie and an `Origin` value listed in `ALLOWED_ORIGINS`. Connections without either are rejected. The server joins the socket to each channel the authenticated user currently belongs to.

All payloads are defined in `@relay-chat/shared` and are validated on receipt. The server limits each socket to 30 events per 10 seconds and rejects Socket.IO payloads over 16 KiB.

| Direction       | Event             | Payload                                                | Result                                                                                                                                                                                                                                                        |
| --------------- | ----------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Client → server | `channel:join`    | `{ channelId }`                                        | Joins the channel room only when the caller is currently a member. Its acknowledgement is `{ ok: true }` or `{ ok: false, error }`. This follows a successful REST join.                                                                                      |
| Client → server | `message:send`    | `{ channelId, body, clientMessageId }`                 | The server checks current membership, stores the message before emitting it, and acknowledges with the stored message or a typed error. Reusing a `clientMessageId` for the same user returns the original stored message and does not broadcast a duplicate. |
| Client → server | `typing:start`    | `{ channelId }`                                        | Relayed to other currently authorised channel sockets.                                                                                                                                                                                                        |
| Client → server | `typing:stop`     | `{ channelId }`                                        | Relayed to other currently authorised channel sockets.                                                                                                                                                                                                        |
| Server → client | `message:new`     | `{ id, channelId, userId, body, createdAt, editedAt }` | A persisted new message. Timestamps are ISO-8601 strings.                                                                                                                                                                                                     |
| Server → client | `typing:start`    | `{ channelId }`                                        | Another authorised member began typing.                                                                                                                                                                                                                       |
| Server → client | `typing:stop`     | `{ channelId }`                                        | Another authorised member stopped typing.                                                                                                                                                                                                                     |
| Server → client | `presence:update` | `{ userId, status }`                                   | `status` is `online` or `offline` for a member sharing a channel room.                                                                                                                                                                                        |
| Server → client | `error`           | `{ code }`                                             | Typed protocol error: `INVALID_PAYLOAD`, `NOT_AUTHENTICATED`, `NOT_A_MEMBER`, `RATE_LIMITED`, or `INTERNAL_ERROR`.                                                                                                                                            |

Before handling every client event, the server checks the user’s current ban state and channel membership in PostgreSQL. Before broadcasting a channel event, it removes sockets whose owners no longer have membership, so a removed member cannot receive a later channel event.
